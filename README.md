# @jvavscratch/types

Type definitions for Jvavscratch project, providing TypeScript types and interfaces.

## Features

- Core type definitions
- Scratch type representations
- UUID utilities
- Interface definitions

## Installation

```bash
npm install --save-dev @jvavscratch/types
```

## Usage

```typescript
import { BlockType, ProjectConfig } from '@jvavscratch/types';

// Use type definitions
```
